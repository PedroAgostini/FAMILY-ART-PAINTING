# Imagens dos cards de serviços

Nove imagens fotorrealistas criadas com a ferramenta integrada `image_gen` em 26/10/2026 para substituir as imagens de banco dos cards. Referência visual: casas antigas de Massachusetts, acabamento branco, madeira aparente e luz natural das fotos existentes da Family Art.

Os JPGs nesta pasta são as versões otimizadas usadas em `index.html`. Os PNGs em `originals/` preservam os arquivos gerados. O arquivo `manifest.json` registra os prompts completos, a ferramenta, o arquivo de origem e os textos alternativos.

As imagens geradas representam os serviços; não são registros de trabalhos executados pela empresa. Os três cards com a indicação “Our work” continuam usando as fotos originais, assim como o portfólio.
